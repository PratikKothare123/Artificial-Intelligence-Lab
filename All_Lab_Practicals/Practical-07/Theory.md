# Practical 07 – Family Relationship using Prolog

## Aim
To write a Prolog program to demonstrate the concept of family relationships.

---

## Introduction
Prolog (Programming in Logic) is a declarative programming language used in 
Artificial Intelligence. It is based on facts and rules to solve problems.

Family relationship problems are commonly used to demonstrate how Prolog 
represents knowledge and performs logical reasoning.

---

## Concept
In Prolog, knowledge is represented using:

- Facts → Basic information (e.g., parent relationships)
- Rules → Logical relationships derived from facts

Example:
If A is parent of B, and B is parent of C, then A is grandparent of C.

---

## Relationships Implemented
- Parent
- Father
- Mother
- Grandparent
- Brother
- Sister

---

## Working Principle
1. Define facts (parent relationships).
2. Define rules using logical conditions.
3. Query the program to get relationships.

---

## Advantages
- Simple and logical approach
- Easy to represent relationships
- Useful in AI and expert systems

---

## Applications
- Expert systems
- Knowledge representation
- Natural language processing
- AI-based reasoning systems

---

## Conclusion
The Prolog program successfully demonstrates how family relationships can be 
represented and derived using logical rules and facts.
